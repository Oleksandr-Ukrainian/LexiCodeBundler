# LexiCodeBundler/Unbundler & Obsidian Backup (only MD Without Images and Videos)🔥
A bundler that will convert your huge project into 1 txt file to feed it for ai, or multiple txt files at root folders, supports output as simple names as well, stores memory between sessions

Q: Why it is good?

R: it can bundle a huge projects excluding .png, and extensions, garbage compilation repositories and just packages your project code into 1 file, it's that simple! It is setup for professional work out of the box!

Q: Is it cool?⭐

R: It supports 6 or 7 languages and has absolutely rad customization themes 😎

ADDITIONAL FUNCTIONALITY:

Added Unbundle, added MD files support for Obsidian, so you can backup your projects without the bulk of PNG, Gif, MP4 and other files, only MD text! (P.s. all settings are stored in memory!)
